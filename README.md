# CookieCoutureWebseite

This is my first project that I created as a front-end developer. The project is a multi-page website built using HTML, CSS, SASS/SCSS, and JavaScript. I used my custom Gulp build for task automation.

## Technologies

- **HTML**
- **CSS**
- **SASS/SCSS**
- **JavaScript**
- **Gulp**

## Website Structure

The website consists of several pages:

- **Home**
- **Story**
- **Franchising**
- **Jobs**
- **Catering**
- **Contact**
- **Imprint**
- **Privacy Policy**
  
## The layout was taken from here
[Layout on Patreon](https://www.patreon.com/posts/maket-dlia-101151517?utm_medium=clipboard_copy&utm_source=copyLink&utm_campaign=postshare_fan&utm_content=web_share)

## Features

- **Element appearance animation** on the page (using JavaScript).
- **Burger menu** for mobile devices.
- **Accordion** to display additional information on the **Jobs** page.

## How to view the project

1. Go to the https://firstprojectcookie.netlify.app/ to view the live version of the project.
   
Or follow these steps to run the project locally:

### Steps to run locally

1. Create a new folder and open it in VS Code.
2. Clone the repository:

   ```bash
   git clone https://github.com/OlexandrShyshov/Cookie.git
3. Navigate to the project folder:

   ```bash
   cd Cookie
4. Install dependencies:

   ```bash
   npm install
5. To run the production version (view only):

   ```bash
   gulp docs
6. To run the development version (automatic browser refresh on code changes):

   ```bash
   gulp
